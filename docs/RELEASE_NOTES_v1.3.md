# 果仓助手 (AppleVault) v1.3.0 更新说明

果仓助手 (AppleVault) v1.3.0 是一次重大功能与体验升级。本次版本带来了全新的多账号管理与一键切换、IPA 智能安全兼容性检测与拖放安装、下载文件完整性哈希校验以及在线更新检查等众多核心特性，为管理与安装正版 iOS 应用提供更加稳定、丝滑与安全的体验。

---

## 🌟 核心新特性

### 1. 👥 全新多账号体系，支持一键无缝切换
- **多 Apple ID 支持**：彻底打破单账号限制，支持同时保存与管理多个地区（如中国区、美区、日区）的 Apple ID。
- **直观账号卡片列表**：清晰展示每个账号的头像、昵称、邮箱、所属国家/地区徽章与当前激活状态。
- **一键平滑切换**：切换账号后，已购应用与历史版本检索自动联动当前账号，无需反复重新登录。
- **独立按账号管理**：支持针对单个账号执行退出登录、刷新状态或单独清理钥匙串凭据/Cookie 缓存。
- **本地钥匙串安全加固**：提供自定义钥匙串主密码保护，加密保存本地凭据，修改密码时提供安全防呆确认。

### 2. 📲 设备直装体验增强与 IPA 智能安全体检
- **支持 IPA 拖放载入**：直接将电脑中的 IPA 文件拖拽至窗口即可快速载入。
- **四维智能兼容性检测**：在应用安装入设备前自动执行全方位体检，避免安装失败或装后闪退：
  1. **完整性检测**：校验 IPA 压缩包结构与文件是否损坏；
  2. **官方签名验证**：检查是否包含合法的个人官方正版签名及授权凭据；
  3. **最低系统版本比对**：校验 IPA 的最低 iOS 版本要求是否满足当前真机系统；
  4. **设备架构匹配**：校验 IPA 支持的设备类型（iPhone / iPad）与目标设备是否兼容。

### 3. 🛡️ 下载引擎加固与完整性校验
- **哈希与 ZIP CRC 双重校验**：下载完成后自动校验文件哈希与压缩包 CRC，彻底解决网络抖动造成的大文件损坏问题。
- **安全断点续传**：支持大文件分段断点续传，异常中断后可无缝恢复进度。

### 5. 🔄 在线更新检查与版本感知
- **自动后台更新探测**：启动时每日轻量检查一次 GitHub Releases 最新版本发布状态。
- **关于页全面升级**：在“关于软件”页面新增一键【检查更新】功能，直观展示当前版本、最新版本号、发布时间及更新日志，支持一键直达官方 Release 页面。
